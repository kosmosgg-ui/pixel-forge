## 수령·출력·승인 구분

1. 원본PNG/참조3장/프롬프트txt와SHA/actor·view·동작/프레임·fps 또는ms/생성시각·모델확인여부/출처를 수령한다. JPEG 재저장을 원본으로 취급하지 않는다.
2. 원본·intake·state·spec·참조hash·bible/rules/도구SHA와 baseline PNG+manifest/출력hash를 저장한다. baseline은 기존 파생 결과이며 원본이 아니다. 없으면 만들어낸 state로 통과시키지 않는다.
3. `data/import/<actor>/baseline/<actor>_{sheet.png,manifest.json}` 쌍을 보관한다. 현재5종은 로컬에 보관됨. 새 원본은 기존 intake→make 경로로 처리하고 명시적 로컬 `--out out/<review-run>`에 먼저 출력한다. 누락/시간충돌은 복구 후 다시 실행한다. 임의 @seonggeom 허용목록 생성은 하지 않는다.
4. 수령/변환/기술검사/경고검수/사람미술/권리/정식적용을 분리한다. state의 합격·qa.pass는 변환 경로의 결과이며 Gate C가 아니다. rightsReviewed=false를 자동승인하지 않는다.
5. 현재 baseline/out은Git제외이므로 별도ZIP을 함께 인계한다. 원본이 복원되기 전에는 원래 생성/변환을 완전히 재현할 수 없다. ZIP은새모듈설치/스냅샷게시/원격Git과별개다.

## 이번 검수 결과

캐릭터 전체 공통 팔레트는 사용자 승인으로 바이블에 반영. 그 외 위 미정 수치/새 형식은 제안 상태다. 세라 공통팔레트는31색/알파·실루엣 불변, 미술등급 잠정 B<대상<A48(1회 보정순서확인), ART_HOLD/Gate C PENDING. 현재 원본3장·새방향/컷인/목표물 원화는 미수신이다.

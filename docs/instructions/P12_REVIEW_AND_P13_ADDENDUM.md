## 17. 초상(portrait) 수령 경로 (pixel-forge)
대화창 반신 초상은 도트 변환하지 않는 일러스트 예외(컷인과 같은 계층).
1. `forge intake <file> --kind portrait --as <charId>/<setName>`: 2×2 격자 원본을 4칸으로 자르기(칸 순서: 좌상 → 우상 → 좌하 → 우하 = 요청 문구의 표정 순서), 초록 배경 제거(가장자리 despill 2px), 칸별 투명 여백 정리.
2. 정규화: 높이 720px 캔버스, **머리 꼭대기 y=40 정렬**, 가로 중앙, linear 축소, PNG. 단일 이미지(격자 아님)도 같은 처리.
3. 출력: `art/candidates/portraits/<charId>/<expression>.png` + manifest(`kind: "portrait"`, provenance 11필드, aiUsed true).
4. QA: 4칸 머리 크기 편차 ≤ 8%(초상 일관성), 잘림 검사(머리·어깨), 배경 잔여 0.
5. 표정 ID: sera = default / determined / smile / surprised, leona = default / smile, clerk = default, mia = default, elder 없음.

## 10. 검기 연출 보강 (pixel-forge, P11 결과 위에서)

1. 프레임 구성(3프레임 유지, ms 불변):
   - f0: 바깥 호(현재) + 안쪽 82~88% 반지름에 2px 두께 보조 호(fxPalette `C` 진한 청록), 각도 범위의 앞쪽 60%만.
   - f1: 바깥 호 2px(밝은 `c` + 끝단 `w`) + 보조 호 전체 각도, 호 사이(88~100%)를 `n` 점묘 1/3 밀도(규칙 격자, 랜덤 금지 — 시드 고정 패턴).
   - f2: 바깥 호 1px `C` + 점묘만 남김(사라짐).
2. 끝단(휘두름 끝 방향) 3~4px만 `w` 하이라이트.
3. QA 추가: 프레임별 불투명 픽셀이 부채꼴 면적의 **≤ 35%**(적 가림 방지), 바깥 호 90~100%·각도 ±5° 기존 검사 유지.

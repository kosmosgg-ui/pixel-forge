## 2. 타이틀 화면
- 메뉴: 새 게임 / 계속 / 설정 / 크레딧 / 종료. 키보드(↑↓·Enter·Esc)와 마우스 모두.
- 계속: 저장 없음 → 비활성 + 이유. 저장 있음 → "마지막 완료 지점: <미션 이름>" + 안내 "전투 중 종료하면 미션 시작점에서 다시 시작합니다". 손상·호환 불가 → 기존 저장 보호 규칙대로 안내(덮어쓰기 금지).
- 새 게임: 기존 저장이 있으면 확인 대화("기존 진행이 사라집니다" — 실제로는 기존 백업 규칙 따름, 동작을 문구와 일치시킬 것).
- 배경: 현재는 단색 + 제목 텍스트(키아트 미확정). 키아트 자리(TextureRect, 없으면 숨김)만.
- 시작 장면을 타이틀로: 데모 빌드 진입점만 변경(기존 demo_080.tscn 흐름은 타이틀 → 새 게임/계속에서 호출). main.tscn 불변.

## 5. 대사 시스템 (D-NARR)
1. 데이터: `data/dialogue/demo_d1.json` — NARRATIVE_D1_v1_0.md의 장면을 아래 형식으로 옮긴다(문구 수정 금지, 오탈자만 `질문:`).
   ```json
   { "version": 1, "approved": true,
     "scenes": { "S01_opening": { "trigger": "pro01.before", "mode": "panel",
       "lines": [ { "speaker": "sera", "portrait": "sera_default", "text_key": "dlg.S01.001" } ] } } }
   ```
   문구 자체는 `ko.json`의 `dlg.*` 키로.
2. 표시 모드 2종: `panel`(미션 전·후 — 하단 대화창 + 반신 초상 자리, 전투 정지 상태에서만), `bark`(미션 중 — 화면 상단 한 줄, 3초, 전투 계속, 입력 막지 않음, 목표 판정과 독립).
3. 조작: Enter/Space/클릭 다음 줄, 길게 누름 또는 Tab 장면 건너뛰기(확인 없음), L 로그(현재 시도 중 본 대사). 대사 속도·자동 넘김은 설정 연동.
4. 초상: `portrait` ID → 이미지가 없으면 이름표만(이미지는 M1·M2에서). 화자 이름표 색은 인물별 1색.
5. 트리거 연결: 초안의 trigger 목록(미션 전·후, 특정 이벤트 — 첫 성장, 단서 확보, 대장 등장, 성문 위험, 전직 확정, 데모 종료). 같은 시도에서 bark 중복 금지, 재도전 시 미션 전 panel은 "건너뛸까요?" 없이 자동으로 짧게(첫 줄만) — 초안 표기 `retry: "first_line"` 따름.
6. 본 대사 기록: 캠페인 저장의 기존 영속 플래그 영역에 `seen_scenes`만(스키마 변경이 필요하면 구현 말고 `질문:`).
7. 테스트: 장면 수·트리거 연결 수 = 초안 표와 일치, panel 중 전투 시계 정지, bark 중 전투 진행·판정 동일(같은 seed 봇 결과 해시 동일 — 대사 켬/끔), 건너뛰기·로그·재도전 동작.

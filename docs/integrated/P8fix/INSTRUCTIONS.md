## 1. 기준 A 이미지 교체 (불통과 "차이 97%"의 원인)
- 원인: 기획 세션 실수. 저장소에 들어간 calibration-v2/A_gpt-import-sera.png는 **예전 SD 세라(32×59)** 판이고, 6등신 세라로 바꾼 갱신판(47×64)이 전달되지 않았다. 결과(48×64)는 정상이다.
- 처리: docs/integrated/P7close/calibration-v2/A_gpt-import-sera.png와 calibration-v2-sheet_4x.png를 이 zip의 calibration-v2/ 두 파일로 교체(커밋 메시지에 "기준 A 교체: 6등신 세라, 사용자 결정 18:31").
- A 생성 설정(질문 ②의 답): 원본 samples/sera_ref_tall_gpt.png(흰 배경 일러스트) → 가장자리 연결 흰 영역 제거(min ≥ 225, max−min ≤ 14) + 2px 열림 → 알파 사전곱 BOX 축소(키 64) → 알파 ≥ 128 → median-cut 32색, 디더 없음 → 셀 64×80, 발 (32,78) 가운데 정렬.
- 재현성 기준 변경: 픽셀 일치 대신 **실루엣 IoU ≥ 0.90**(발 기준 정렬 후) + **불투명 픽셀 평균 OKLab ΔE ≤ 0.05**. 이유: 폭 반올림(47 vs 48) 1px 차이로 픽셀 비교는 의미가 없다.
- 교체 후 art-judge v2 보정 확인을 1회 다시 실행(새 A로 D<C<B<A 유효한지). 무효면 판정자 순서·이유를 그대로 보고(재시도 금지).

## 2. 잘림 기대값 (질문 ①의 답)
- 기대값 3은 기획 세션이 **2px 팽창한 마스크**로 잰 값이라 틀렸다. 팽창 없이 다시 재면 1개(19번, 오른쪽 끝 x=639).
- 정의를 고정한다: "잘림 = 알파 ≥ 128 픽셀이 이미지 바깥 1px 행·열에 닿은 스프라이트". 이 정의로 나온 값과 스프라이트 번호를 기록하고, 테스트는 그 값을 골든으로 고정. 2가 나온다면 두 번호와 닿은 변을 보고에 적는다(근거만, 재작업 불필요).

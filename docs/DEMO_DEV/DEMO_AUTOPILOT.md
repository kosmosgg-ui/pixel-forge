## 1. 생성 공정 (모든 AI 그림 공통)
1. **요청 문구 = 데이터**: pixel-forge `data/projects/seonggeom/prompts/`에서 조립(`forge prompts`). 새 종류는 이 문서 3절 규격으로 템플릿을 먼저 추가하고 골든 테스트. 채팅에서 즉석 문구를 만들지 않는다.
2. **공통 문구 필수 요소**: clean anime game illustration(캐릭터) / modern JRPG illustration(초상·컷인·키아트), bold clean dark lineart, **flat cel shading 2–3 tones, large clean color areas, no texture, no noise, no speckled details**, no gradients/glow, flat pure green #00FF00 background(녹색 계열 대상은 magenta #FF00FF), no shadow/ground/effects/text/labels, generous spacing, same foot baseline, do not shrink any frame.
3. **참조 첨부**: art-source에 고정된 참조만 첨부(해시 기록). 세라 = ref·turnaround·size_ref, 레오나 = 승인된 design, 직업 = 승인된 의상 원화 + 세라 ref. 참조 없는 캐릭터 동작 생성 금지.
4. **생성**: `$imagegen` 기본 도구, 2K 이내(긴 변 ≥ 1536 권장, 비율 3:1 이하 — 6프레임 이상 시트는 3:1 한도 확인, 넘으면 두 장으로 나눠 요청하고 intake에서 합침).
5. **보관**: 결과 원본을 즉시 `forge intake --archive` → art-source 커밋. provenance: `origin: "codex-imagegen"`, `model: <도구가 보고한 모델명 또는 "gpt-image (Codex 내장, 모델명 미확인)">`, `promptFile`, `promptSha256`, `references[]`(해시), `createdAt`, `attempt`.
6. **변환·QA**: `forge make`(캐릭터) 또는 kind별 경로 → 2절 자동 판정 → 합격만 후보 등록.
7. **사용량 기록**: `docs/DEMO_DEV/AUTOPILOT_LEDGER.md`에 요청 1건 = 1줄(항목 ID, 시도, 결과). 점검 보고에 합계.

## 2. 자동 합격 기준 (사람 판정 대체)
### 2.1 원본 단계(변환 전) — 하나라도 실패하면 재시도
- 배경: 가장자리 95% 이상이 지정 크로마색, 체크무늬·그라데이션 없음.
- 프레임 수·줄 구성 일치, 프레임 간 분리 가능(연결 성분), 잘림 없음(잉크가 이미지 가장자리 접촉 0).
- 텍스트·숫자 없음(문자형 작은 성분 검출 경고).
- **동일인 검사**(세라·레오나·직업): 머리 색·눈 색·리본·갑옷 주색의 평균 색이 참조 대비 ΔE ≤ 12, 망토 색 영역(등 뒤 큰 천 성분) 검출 시 **불합격**(세라 기본·직업 중 망토 없는 직업). 뒷면 요청에서 눈 색 픽셀 검출 시 불합격.
- 크기: 프레임 간 키 편차 ≤ 6%(서 있는 프레임 기준).
### 2.2 변환 단계 — 기존 pixel-forge QA 전부 + 아래
- 녹색 잔여 0(despill → 공통 팔레트 순서), 공통 팔레트 32(세라·직업)/24(적), 고립 픽셀 비율 ≤ 기존 세라 후보 수준(측정값 기준선 기록).
- 발 앵커·셀 규격 = 승인 셀(세라 112×80 / 발 56,78 등), 2배 표시 짝수 스냅.
### 2.3 그림 판정(코덱스 시각 판정)
- `forge lineup`으로 보정 세트 v2(D<C<B<A48) + 대상 1장. **기준 4장의 순서를 먼저 스스로 다시 매겨 맞을 때만 유효.** 등급 B 이상 합격. 관찰 3줄 기록.
- 순서가 틀리면 판정 무효 → 그 항목은 `NEEDS-CLAUDE`로 점검 묶음에 넣고 다음 항목 진행.
### 2.4 재시도
- 실패 사유 → `fixes.json` 고치기 문구 선택(잘림·크기 다름·다른 캐릭터·다리 안 움직임·뒷면 얼굴·배경·텍스트·망토) → 같은 대화가 아니라 **새 요청 + 고치기 문장 추가**.
- 항목당 최대 3회. 3회 실패 → `FAILED-3`로 기록, 다음 항목. 같은 사유로 3개 항목 연속 실패하면 요청 템플릿 결함으로 보고 해당 종류 중단(`BLOCKED-TEMPLATE`).

```
이미지 생성: 이번 n장 / 누적 N장
클로드 판정 요청: …(NEEDS-CLAUDE 항목)
다음: Q…
```
- 이미지는 묶음 시트 우선, zip 이미지 합계 20MB 이하(Windows 빌드 별도).

## 6. 즉시 중단 조건(전체 멈춤)
- 저장 손상·기존 회귀 실패를 1회 수정으로 못 고침.
- 정사와 다른 그림을 합격시킨 사실 발견(망토·눈 색 등) → 해당 후보 철회 후 보고.
- 이미지 도구 사용 불가·한도 도달.
- 참조·원본이 art-source에서 해시 불일치.

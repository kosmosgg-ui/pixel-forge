## 0. 원칙
1. **주제**: "지킨다는 선택이 성검의 진짜 힘이 된다." 데모 3미션은 세라가 '지킬 대상'을 하나씩 넓혀 가는 구조 — 마차의 피난민(사람 몇 명) → 의뢰(마을) → 관문(왕국).
2. **인과 보존**: 데모에서는 GDD 인과 1~2단계까지만. 수호석 이상은 **암시만**(CH1-01 단서). 로델릭 이름·위조 사실은 **나오지 않는다**.
3. **분량**: 미션 전·후 대화(panel)는 6~10줄, 미션 중 한 줄 대사(bark)는 2~6개. 튜토리얼 안내 UI(tutorial_guide)와 문장이 겹치지 않게 — bark는 감정·상황, 안내 UI는 조작.
4. **말투**: 세라 — 성실하고 곧은 초보 검사. 레오나에게 존댓말, 아이·동년배에게 반말, 혼잣말은 짧게. 레오나 — 담백한 선배 기사, 반말, 칭찬은 짧고 지적은 정확하게.
5. **판정과 독립**: 대사가 목표·보상·시간을 바꾸지 않는다. bark가 없어도 진행 가능.

# 《성검의 맹세》 스팀 데모까지의 격차 점검 (2026-10-23, 클로드 총괄 검수)

기준 자료: 통합 기획서 v1.0(2026-10-22), Steam 데모 MVP 명세 v1.1, 승인 결정 v1.2(D01~D06), DEMO-020~091 인계서, G1/G2·P10 기록, codex/g2-approved-handoff 브랜치(양 저장소) 실제 파일.
이 문서는 점검·제안이다. 새 수치·정사·정식 승격 승인이 아니다. 코덱스는 이 문서를 작업 순서 참고로만 쓰고, 실제 작업은 클로드 지시문으로 받는다.

## 1. 현재 위치 한 줄
**게임 흐름은 끝까지 이어지는 도형 데모**(3미션 → 전직 확정 → 선택 직업 체험 → 종료, 저장·재시도 포함). **아트는 옆모습 후보만 붙은 단계**이고, **오디오·타이틀·설정·대사·전장 아트·스팀 준비는 사실상 0**이다.

| 영역 | 상태 | 비고 |
| --- | --- | --- |
| 전투 코어(이동·회피·자동 검술·F 필살기·성장) | 구현 + 기술 검증 | 회피·F 수치는 D06 "시험안" 그대로(미승인) |
| 3미션 콘텐츠 | 구현, Gate C 통과~조건부 통과 | CH1-01 길이·탐색 과제 |

| 저장(미션 경계)·진단 | 구현 + 검증 | 전투 중 재개 제외 |
| 캐릭터 아트 | 후보(ART_HOLD) | 세라·적 4종 옆모습만, 정식 승격 전 |

## 2. 데모 완성에 필요한 것 (영역별 작업 목록)

### 2.1 캐릭터·적 아트 (진행 중 — pixel-forge 라인)
| 항목 | 남은 일 | 완료 기준 |
| --- | --- | --- |
| 세라 4방향 | 정면·뒷면 idle4·walk6 → 정면·뒷면 attack5·hit3·dodge3(MVP상 각 방향) | 이동 방향별 행 전환, 옆 33프레임 보존, 공통 32색 |
| 세라 크기 일관성 | 동작 간 머리 폭 14~19px 차이 판정 | 같은 발 기준선 비교 시트로 사람 판정 |
| 적 4종 | 고블린·오크 접지 뜸, 대장 사망 잘림 해결 | 경고 0 또는 사람이 허용 판정 |
| 오크 대장 방향 | **결정 필요**: 기획은 앞·뒤·옆, 현재 옆+반전만 | 방향 규칙 확정 후 패턴 3종 × 방향 요청 |
| 직업 3종 외형 | 체험에 실제로 쓰는 동작 목록 확정 → 의상 원화 → 동작 시트 | D03: 선택 직업만 체험 → 3직업 모두 필요(누가 무엇을 고를지 모름) |
| 피격 플래시·사망 | 구현됨 | 실제 화면 가독성 검수 |

### 2.2 이펙트·컷인
- **검기를 실제 판정에 맞춰 다시 생성**(P11 4절). ⚠ P11 지시문은 기본 검사(C-B, reach 110 / angle 100·140)만 다룬다. **직업 체험 수치도 다르다**: GUARD 135/145°, SWIFT 110/90°, RUNE 125/110° → 직업별 검기 변형이 추가로 필요하다(P11 표 추출 범위에 `demo/data/demo_080_classes.json` 포함 지시 필요 → P11 보충 1줄).
- 직업 고유 효과 표현: GUARD 보호막(10·1.5초)·넉백, SWIFT 2연격, RUNE 표식 3중첩·폭발(반경 85). 현재 전용 이펙트 없음.
- 공통 F(반경 380) 충격파 크기 검증, 회피 잔상/먼지, 성장 선택 시 연출, 보스 예고(빨강·주황) 그래픽.
- 컷인 원화 1장(상반신, 얼굴·손·검 잘림 없음) + 화면 배치·UI 안전영역 결정.

### 2.3 전장·목표물·배경 (미착수 — 가장 큰 덩어리)
- **규격 결정 필요**: 타일 크기(후보 32×32 1배? 16×16?), 카메라 각도(캐릭터와 같은 30° 높은 시점), 광원 방향, 장애물 가림 규칙.
- 장소 3곳: PRO-01 고블린 습격지(마을 외곽·마차), CH1-01 폐허 3구간(진입·내부·탈출 — 장애물이 실제 충돌과 일치해야 함), CH1-02 서쪽 관문(성문 + 손상 단계).
- 목표물: 피난민 마차(고정 1포즈 + 피격 표시), 성문(정상·손상·파괴 판정 표시 필요 여부 결정), CH1-01 단서 지점·출구·조사 지점 A/B/C 표식.
- 방법: 전체 배경 한 장이 아니라 **모듈 타일 + 소품**. 한 구역을 시험 제작해 가독성 확인 후 확대.

### 2.4 UI·HUD
- HUD 아트: 세라 HP, 목표/성문·마차 HP, 시간, 보스 HP·예고, EXP/레벨, F 게이지, 회피 쿨다운.
- 성장 카드(효과·랭크 표시), 결과 화면(성공/실패 원인·저장 상태), 전직 선택 화면(3직업 비교 — 직업 원화가 들어갈 자리).
- 한국어 글꼴: NotoSansKR 있음 → 픽셀 게임에 맞는 글꼴 결정(가독성·라이선스).
- 데모 종료 화면: "데모 플레이 종료" + 위시리스트 유도(App ID 확보 후).

### 2.5 서사·대사 (기획 공백)
- MVP 명세가 요구: 미션 전·중·후 짧은 장면, 여러 줄 큐, 스킵·로그. **대본이 아직 한 줄도 승인되지 않았다.**
- 필요한 것: ① 데모 범위 장면 목록(약 8~12장면: 오프닝, PRO-01 전후, 길드 의뢰, CH1-01 단서 사건, CH1-02 전후, 전직 선택, 데모 종료), ② 등장 인물과 초상(세라 + 실제 등장 인물만), ③ 단서 사건 문구(현재 placeholder), ④ 대사 표시 시스템(현재 없음).
- 정사 근거: 마스터 GDD의 1장 설정. **구 프로토타입 스토리 데이터(09_story_dialogue.json 등) 혼입 금지** 여부를 먼저 확인.

### 2.6 오디오 (전무)
- 최소 BGM 4곡: 메뉴, 일반 전투, 보스/긴장, 결과(재사용·레이어 우선).
- SFX 약 20종: 검술 3단, 피격, 처치, 회피, 필살기(준비·발동), 성장 선택, 목표 위험(성문·마차), 보스 예고, 성공/실패, UI 확인/취소.
- 출처 결정: 유료 에셋 팩 / 무료(CC0) / AI 생성(스팀 AI 공개 대상) 중 선택 → 결정 필요.
- 시스템: Master/BGM/SFX 음량, 동시 재생 제한, 일시정지·Alt-Tab 처리.

### 2.7 타이틀·설정·접근성 (없음)
- 타이틀: 새 게임 / 계속(저장 상태 안내, "계속은 미션 시작점부터") / 설정 / 크레딧 / 종료.
- 설정 최소: 창·전체화면, 해상도(1280×720·1920×1080 정수 배율), 음량 3종, 키 변경(이동·회피·F, 충돌 안내), 화면 흔들림 끄기, 섬광 완화, 컷인 단축, 대사 속도.
- 크레딧: 도구·글꼴·음원 라이선스, AI 사용 고지.

### 2.8 성능·배포
- Godot 기준 버전 고정(4.7.2, P11 3절).
- Windows 실기 검수(진용님 PC): 시작·3미션·저장 복원·전직·체험, 프레임 p95/p99.
- 목표 PC·최소 사양 결정(실측 후).
- 아트 통합 후 CH1-02 최대 웨이브(적 64 동시 + 대장 + FX) 부하 재측정.

### 2.9 스팀 준비 (미착수, 제작과 병행 가능)
- Steamworks 가입·앱 등록비(100달러) → 본편 App ID + 데모 App ID.
- 본편 "출시 예정" 상점 페이지: 캡슐 이미지 5종, 스크린샷 5장 이상, 설명문, 태그, 트레일러(권장).
- Content Survey AI 공개: 플레이어가 보는 AI 사용 = 캐릭터 원화(GPT) 기반 스프라이트·컷인. 이펙트는 코드로 그림(AI 아님). → **에셋 등록부**(MVP 7.2의 11개 열)를 provenance에서 자동 생성.
- 연령 등급·개인정보(진단 로그 기본 꺼짐 유지).
- 이벤트 일정: 스팀 넥스트 페스트 참가 여부·시기(데모 공개 시점 결정의 기준).

### 2.10 검수·플레이테스트
- Gate C 대상: 아트 통합 빌드, SWIFT·RUNE 체험, CH1-01 사람 소요 시간, 첫 성장 체감, 조사 정보 가치.
- 외부 테스터 3~5명(MVP 3.2) — 모집 방법·관찰 질문지·합격 기준을 **테스트 전에** 정한다.

## 4. 보완할 것 (있지만 약하거나 문서끼리 어긋나는 것)

1. **통합 기획서 v1.0이 오래됐다**: 망토·파란 눈(→ 망토 없음·갈색 눈), 방어 대상 placeholder(→ 피난민 마차), 아트 9절이 이전 Sprite Factory 연구 트랙(SF-004/005) 기준 → 현재 pixel-forge·GPT 일러스트 라인으로 갱신 필요. 승인 셀 5종·32/24색 공통 팔레트·2배 표시도 반영.
2. **두 아트 트랙 정리**: seonggeom 안의 Sprite Factory(SF-00x, PR #19 등)와 pixel-forge 라인이 공존 → 데모 아트는 pixel-forge로 일원화하고 SF 트랙은 "연구 보관"으로 표시할지 결정.
3. **열린 PR 19개 + 브랜치 다수**: 전부 Draft·미병합. 데모 기준 브랜치 하나로 정리하는 병합 계획 필요(무엇을 버리고 무엇을 올릴지).
4. **CH1-01 길이·탐색**: 봇 73초 — 사람 실측 필요. 적 수·HP만 늘리지 않는다는 원칙 유지 → 대안은 탐색 이벤트·대사·지형 동선.
5. **직업 체험 F 사용 기회 없음**: 체험이 31~37초에 끝나 45초 해금 전 종료. 체험에서는 F를 즉시 해금하는 예외 또는 편성 연장 결정 필요.
6. **SWIFT·RUNE 사람 검수** 미실시.
7. **첫 성장 속도**: 보완 후 34~42초(봇). 사람 체감 확인.
8. **군집 속 세라 가독성**: CH1-02 적 64 동시 생존에서 겹침 확인됨 → 외곽선·발밑 고리 효과를 실제 화면에서 판정, 부족하면 적 채도 낮추기 검토.
9. **검기와 판정 불일치**(P11 진행 중) + 직업별 변형 누락(2.2절).

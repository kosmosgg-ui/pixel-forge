# P10 — UI 키트

## 목표
`kind: "ui"`를 구현해 게임 UI 기본 부품을 바이블 색으로 일관되게 만든다. 엔진이 늘려 쓰는 9-slice 패널, 상태별 버튼, 게이지(§1 원칙 6: 전 에셋 일관성).

## 읽을 것
- ARCHITECTURE §1, §4, §7, §10(manifest)
- rules: `outline`, `qa`

## 작업 순서
1. 바이블 `ui`: 패널·버튼·게이지에 쓸 재질 키와 모서리 반경(px), 테두리 두께(1~2px)
2. `render/src/ui/nine-slice.ts`: 최소 크기 패널 + 9-slice 경계(left, top, right, bottom) 메타. 모서리는 `rect` chamfer 재사용
3. `render/src/ui/button.ts`: 상태 4종(normal, hover, pressed, disabled) — 명도 단계 이동으로만 파생, pressed는 1px 아래로
4. `render/src/ui/gauge.ts`: 빈 틀 + 채움 줄(1px 단위 늘리기용 세로 슬라이스) + 끝 캡
5. 출력: `out/<id>/ui/*.png` + manifest에 9-slice 경계·상태 목록
6. QA `ui.nine-slice`(가운데 영역 늘려도 모서리·테두리 픽셀 보존), 공통 `palette.conformance`·`alpha.binary`

## 핵심 테스트
- 9-slice 메타로 2배·3배 늘린 결과에서 모서리 픽셀 동일
- 버튼 4상태의 실루엣 동일(pressed는 1px 이동만)
- 게이지 0%·50%·100% 조합이 캔버스 안

## 범위 밖
폰트 렌더링, 아이콘 글리프(P7 아이콘 재사용), 애니메이션 UI.

## 수락 기준
```
pnpm build && pnpm test -- --reporter=dot
pnpm forge build-all sample-ui
```
pixel-reviewer에 UI 키트 시트 1장 검수 요청: 바이블 캐릭터·아이콘과 색이 한 세트로 보이는지.

# P8 — 손맛 키트

## 목표
타격감·드롭 쾌감을 만드는 보조 스프라이트를 **기존 스프라이트에서 자동 파생**한다. 새 그림을 그리지 않고 같은 Spec 하나로 손맛 세트가 따라 나온다(§1 원칙 6: 손맛 연출).

## 읽을 것
- ARCHITECTURE §1, §6(외곽선·검증 훅), §10(manifest `motion`)
- rules: `outline`, `qa`

## 작업 순서
1. `render/src/derive/` 아래 파생기, 모두 IndexedRaster → IndexedRaster(순수, 결정론)
   - `hit-flash.ts`: 피격 흰 실루엣 프레임 — 불투명 픽셀 전부 바이블 fx 흰색(외곽선 유지 옵션)
   - `shadow.ts`: 바닥 그림자 타원 — 실루엣 발밑 폭 기준 타원, 바이블 `shadow` 색 1색(반투명 금지, 디더 없음)
   - `shatter.ts`: 사망 파편 — 실루엣을 시드 PRNG로 4~8조각(보로노이 시드 점)으로 분할, 조각별 PNG + 무게중심 오프셋 JSON
   - `sparkle.ts`: 드롭 아이템 반짝임 루프 — 아이콘 실루엣 위 하이라이트 점 2~4개가 프레임마다 이동(4프레임), 바이블 fx 색만
   - `rarity-glow.ts`: 등급 테두리 발광 — P7 rarity border 바깥 1px에 glow 색, 2프레임 깜빡임
2. 바이블 `fx`: `{ shadow: "<hex>", flash: "<fx 색 인덱스>" }` 기본값
3. `cli`: `forge build`가 파생물도 함께 출력(`out/<id>/fx/`), manifest에 파일·프레임 목록 기록
4. QA: 파생물도 `palette.conformance`, `alpha.binary`, `bounds.canvas` 통과. 파편 조각 픽셀 합 = 원본 실루엣 픽셀 수

## 핵심 테스트
- hit-flash 결과의 불투명 마스크 = 원본 마스크
- shatter: 같은 시드 → 같은 조각, 조각 합집합 = 원본, 조각끼리 겹침 0
- shadow 타원 폭이 발밑 폭에 비례, 캔버스 안
- sparkle 4프레임 루프 첫·끝 연결 자연스러움(점 이동 ≤ 1px)

## 범위 밖
파티클 시스템(엔진 몫), 화면 흔들림·히트스톱(엔진 몫, manifest 힌트만).

## 수락 기준

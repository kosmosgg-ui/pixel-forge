# P9 — 바닥 타일·배경

## 목표
`kind: "tile"`을 구현해 전투 바닥을 만든다. 캐릭터·몬스터가 묻히지 않는 낮은 대비의 반복 타일과, 단조로움을 깨는 장식 산포를 자동 생성한다(§1 원칙 6: 군중 속 가독성).

## 읽을 것
- ARCHITECTURE §1, §4(램프), §5, §7
- rules: `qa`

## 작업 순서
1. 바이블 `sizeClasses`에 `tile16`/`tile32`, 바이블 `ground`: 바닥용 재질 목록과 캐릭터 대비 목표(OKLab L 차 ≥ `rules.qa.contrastMinL`)
2. `render/src/tile.ts`: 반복 타일 — 가장자리가 이어지는 노이즈 패턴(시드 PRNG, 주기 = 타일 크기), 재질 램프 2~3단계만, 고립 픽셀 정리 동일 적용
3. `render/src/scatter.ts`: 장식 산포 — 돌·풀 등 소품 Spec(작은 `item` 재사용)을 넓은 판 위에 최소 간격(포아송 디스크) 배치, 시드 결정론
4. `cli`: `forge tile <spec>` → `out/<id>/tile.png` + 3×3 반복 미리보기, `forge scatter <project> --size 320x180 --seed n`
5. QA `tile.seamless`(이음매 좌우·상하 픽셀이 반복 시 패턴 연속), `tile.contrast`(바닥 평균 L과 캐릭터 평균 L 차 ≥ 임계), `crowd.readability`를 타일 배경 위에서 재실행

## 핵심 테스트
- 타일을 2×2로 이어 붙였을 때 이음매에서 끊김 0
- 같은 시드 → 같은 타일·같은 산포
- 산포 소품 간 최소 간격 보장, 판 밖으로 나가지 않음

## 범위 밖
오토타일(벽·절벽 47타일 규칙), 시차 배경, 조명.

## 수락 기준

```
pnpm build && pnpm test -- --reporter=dot
pnpm forge tile data/specs/sample-tiles/grass.spec.json
pnpm forge crowd sample --count 50 --seed 1
```

# P6.5 — 품질 고도화: 픽셀 그리드 모드 (사용자 승인)

## 배경
도형 조합 방식은 덩어리 인형처럼 보이는 구조적 한계가 있다. 32px 이하는 픽셀 그리드를 직접 설계하는 쪽이 낫다.
원칙: 그림을 만드는 맨 앞 단계만 교체. 팔레트·외곽선·리그·검수·출력은 재사용. 품질 목표는 `docs/quality-ref/`의 시안.

## 작업
1. 그리드 파츠 형식(§7.3.1): `rows` + `legend`(재질:단계, `@eye`, `@outline`). 외곽선은 엔진이 붙인다.
2. 프레임 모드(`mode: "frames"`): rest grid + 애니별 프레임(grid 또는 base 위 patch). 기존 QA 전부, 깜빡임은 patch 밖 기준.
3. 아톰 모드(`mode: "atoms"`): 파츠 = 그리드 아톰. 팔다리 각도 변형(0, ±45, 90 …) + 남은 각도만 RotSprite, 변형 없으면 경고. 머리 회전 금지(±15° 이내 1px 이동).
4. `.claude/skills/pixel-studio/SKILL.md`: 그리드 → `forge render --sheet 8` → pixel-reviewer → 수정, 최대 4회. 설계 체크리스트.
5. 고블린·스켈레톤을 프레임 모드로 재제작(quality-ref 그리드 → 재질:단계 범례, rest + idle 4 · attack 4 · hit 2 · death 3). 도적을 아톰 모드로 재제작해 도형 모드와 비교 시트.
6. manifest `motion.shadow = { w: 발 폭 + 4, h: 3 }`.

## 수락 기준
- 고블린·스켈레톤 pixel-reviewer 20/24 이상 + quality-ref 대비 "같은 수준 이상"
- 도적 도형 vs 아톰 비교 시트(`forge review compare` → `out/compare/review.png`), 보고 문서에 경로
- 도형 모드 유지. 기본 모드는 비교 결과를 보고 사용자가 정한다.

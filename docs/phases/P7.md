# P7 — 아이템 아이콘 + 변형 생성기

## 목표
`kind: "item"`을 구현해 아이콘을 대량 생산한다. 한 Spec에서 등급·색·파츠 변형을 결정론적으로 뽑아 상점·드롭 아이콘 수십 종을 만든다(§1 원칙 6: 대량 생산).

## 읽을 것
- ARCHITECTURE §1, §5, §6, §7(Spec `kind`), §11(`variants`)
- rules: `cleanup`, `outline`, `budgetFit`

## 작업 순서
1. 바이블: `sizeClasses`에 아이콘 등급 `icon16` [16,16], `icon32` [32,32] (sample-v0에 추가, colorBudget 같은 키)
2. 바이블 `rarity`: `{ common, uncommon, rare, legendary }` → `{ border: "<hex>", glow?: "<hex>" }` (일반·고급·희귀·전설). 예약 색과 같은 거리 규칙(§4)
3. `render/src/item.ts`: `kind: "item"` 렌더. 리그 없이 파츠를 아이콘 캔버스 기준 좌표로 배치(뼈 대신 `anchor: "center"` 하나)
   - 구도 규칙(rule `item.composition`): 실루엣 bbox 중앙 정렬, 무기류(`tags: ["weapon"]`)는 45° 대각 배치(좌하→우상), 가장자리 1px 여백
   - 기존 셰이딩·외곽선·예산 맞춤 그대로 재사용(아이콘 전용 분기 최소)
4. `cli`: `forge variants <spec> [--rarity all|<등급>] [--palette-swap <재질>=<재질>,…] [--part-swap <파츠이름>=<파츠 파일>] [--seed n] [--count n]`
   - 등급: 실루엣 바깥 1px을 rarity border 색으로(외곽선 대신), 출력 `out/<id>/variants/<id>_<rarity>.png`
   - 팔레트 교체: 재질 램프를 통째로 다른 재질 램프로 매핑(새 색 생성 금지 → 바이블 팔레트 안)
   - 파츠 교체: `data/parts/<library>.parts.json`의 같은 슬롯 파츠로 치환
   - `--count n`이면 시드 PRNG로 조합을 뽑는다. 같은 시드 → 같은 목록·같은 바이트
5. QA: 아이콘용 `bounds.canvas`(1px 여백), `color.budget`(icon16 ≤ 8, icon32 ≤ 12 권장값은 바이블), `form.silhouette`(같은 프로젝트 아이콘끼리 IoU ≤ 0.8)
6. 샘플: `data/specs/sample-items/` 검·지팡이·물약·방패 4종

## 핵심 테스트
- 같은 Spec·시드 → 변형 목록과 PNG 바이트 동일
- 등급 테두리 픽셀이 실루엣 바깥 1px에만 있고 색이 바이블 rarity 값
- 팔레트 교체 후 팔레트 밖 인덱스 0, 새 색 0
- 무기 태그 아이콘의 주축 각도 45° ± 5°

## 범위 밖
아이콘 애니메이션(반짝임은 P8), 장비 착용 시 캐릭터 반영.

## 수락 기준
```
pnpm build && pnpm test -- --reporter=dot
pnpm forge build-all sample-items
pnpm forge variants data/specs/sample-items/sword.spec.json --rarity all --count 8 --seed 1
```
pixel-reviewer에 변형 시트 1장 검수 요청: 등급이 한눈에 구분되는지, 16px에서 종류가 읽히는지.

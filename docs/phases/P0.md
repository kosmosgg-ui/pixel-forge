# P0 — 저장소 부트스트랩 + 웹 데모 조사

## 목표
1. 빈 모노레포를 빌드·테스트 가능한 상태로 만든다.
2. 「내려가자 던전」 웹 데모의 그래픽 사양을 조사해 바이블 TODO를 채울 근거를 만든다. **데모 코드는 읽기만, 수정 금지.**

## 읽을 것
- ARCHITECTURE §2, §11(명령 이름만)
- 그 외 금지

## 작업 순서
1. `package.json`(pnpm workspaces, `"type":"module"`, scripts: `build: tsc -b`, `test: vitest run`, `forge: node packages/cli/dist/main.js`), `tsconfig.base.json`(strict, noUncheckedIndexedAccess, ES2022, NodeNext), `vitest.config.ts`, `.gitignore`(out/, .forge-cache/, dist/, node_modules/)
2. 패키지 7개 골격: 각 `package.json`, `tsconfig.json`(references), `src/index.ts`(빈 export), `src/index.test.ts`(1개 통과 테스트)
3. `packages/core/src/errors.ts`: `ForgeError` 클래스(code, message, detail) + 종료 코드 상수
4. `packages/core/src/prng.ts`: mulberry32 시드 PRNG + 테스트(같은 시드 → 같은 수열)
5. `packages/cli/src/main.ts`: `forge --version` → `{"ok":true,"cmd":"version","version":"0.0.0"}` (node:util `parseArgs` 사용, 외부 CLI 라이브러리 금지)
6. **데모 조사** — 사용자에게 데모 저장소 경로를 물어 확인한 뒤, Grep/Glob로만 조사:
   - 내부 해상도·캔버스 크기, 확대 방식(정수 배율 여부, `image-rendering: pixelated` 등)
   - 캐릭터 스프라이트 파일 위치·크기(px)·프레임 구성·로딩 코드(시트 JSON 형식 여부)
   - 애니메이션 종류와 프레임 시간
   - 직업 목록(6종)과 몬스터 목록
   - 전투 배경색 계열
7. 결과를 `docs/demo-probe.md`(40줄 이내 표)로 작성. 각 항목에 근거 파일 경로:줄번호.
8. `data/bibles/dungeon-v0.bible.json`의 TODO 항목에 대해 **제안값**만 demo-probe.md 끝에 적는다. 바이블 파일은 수정하지 않는다(사용자 확정 후 P1에서 반영).

## 범위 밖
도형, 색, 렌더 코드 일절. 데모 코드 수정.

## 수락 기준
```
pnpm install && pnpm build && pnpm test      # 전부 통과
pnpm forge --version                          # 한 줄 JSON
test -f docs/demo-probe.md
```

# P4 — 리그 애니메이션 (포즈 투 포즈)

## 목표
인간형 공용 애니메이션 4종(idle, attack, hit, death)을 한 번 만들고 모든 인간형 캐릭터가 재사용한다.

## 읽을 것
- ARCHITECTURE §8 전체, §9의 `baseline.stable`, `anim.flicker`
- rules: `anim`

## 작업 순서
1. `spec`: `Animation` 스키마(§8.2) + Spec의 `animations`, `overrides` 필드
2. `rig/src/pose.ts`: rest + pose 델타 합성, 각도·오프셋 정수 스냅
3. `rig/src/timeline.ts`: keys + inbetween → 프레임 목록 `{ pose, ms, keyName, fx? }`
   - inbetween은 지정 키의 바로 앞/뒤에만, ease 곡선(in/out) 적용 (`// rule: anim.pose-to-pose`)
   - 키 사이 균등 보간 요청이 들어오면 ForgeError
4. `data/rigs/humanoid-side-v1.anims.json` — 기본값(턴제 전투 기준):
   | 애니 | 키 | 시간(ms) | 메모 |
   | --- | --- | --- | --- |
   | idle | 4 (loop) | 각 180 | 호흡 1px 상하, 무기 끝 1px 흔들림 |
   | attack | ready → windup → strike → follow → recover | 120/140/60/120/160 | strike 뒤 inbetween 1, fx `slash` |
   | hit | flinch → recover | 80/200 | flinch 프레임은 `flash`(전 픽셀 fx 흰색 치환) 옵션 |
   | death | stagger → kneel → fall → lie | 120/160/160/hold | 마지막 프레임 유지 |
5. `render`: 프레임별 렌더 + `fx` 레이어(바이블 fxColors만 사용, 실루엣 위에 합성)
6. `render/src/mirror.ts`: 좌향 버전 = 우향 렌더 후 flipX (재렌더 금지)
7. QA 활성화: `baseline.stable`, `anim.flicker` 실제 판정
8. `cli`: `forge render --anim attack` 등 부분 렌더

## 핵심 테스트
- idle 루프 첫/끝 프레임 연결 시 이동량 ≤ 1px
- root 고정 키들에서 발 최하단 y 동일
- 같은 변환 파츠의 프레임 간 픽셀 변화 0 (flicker)
- 타임라인: inbetween 위치·개수가 정책과 일치

## 범위 밖
몬스터 리그, 노멀맵, 패킹.

## 수락 기준
```
pnpm build && pnpm test -- --reporter=dot
pnpm forge build-all dungeon        # 3종 × 4애니 전부 QA 통과
```
캐릭터 1명 컨택트 시트 1장만 Read해 키포즈 명확성(실루엣만으로 동작 판별 가능?)을 progress에 평가. 수정은 anims.json 포즈 값으로.

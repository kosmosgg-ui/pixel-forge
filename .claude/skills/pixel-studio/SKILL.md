도형 조합 대신 **픽셀을 그리드로 직접 설계**한다. 팔레트·외곽선·리그·검수·출력은 엔진 그대로다.
그리드에는 외곽선을 그리지 않는다(엔진이 크기 등급의 outline 모드로 붙인다).

## 0. 기준 시안
- `docs/quality-ref/`의 시안이 품질 목표다. 같은 종류(크기·역할)의 시안을 먼저 연다(텍스트 그리드면 Read, 이미지면 pixel-reviewer에게).
- 채점은 "시안 대비 같은 수준 이상인가"를 함께 본다.

## 1. 모드 고르기 (사용자 승인 P7, ARCHITECTURE §1 원칙 7)
- 3D 모델이 있는 생물은 이 스킬이 아니라 prerender 모드(/forge). 이 스킬은 모델이 없는 대상(아이콘·얼굴 템플릿·이펙트·리그 없는 생물)과 시안 그리드 이식용.
- **atoms** = 리그로 움직이는 2D 생물(모델 없음). 아래 "아톰 분할" 참고.
- **frames** = 아이템·이펙트·리그 없는 생물(슬라임 등). **shapes** = 시안·자리표시용.
- **frames**: 프레임마다 그리드. Spec `"mode": "frames"`, `grid`(rest), `frames: { idle: [...], attack: [...], hit: [...], death: [...] }`.
  - 바뀌는 부분만 `patch`(`at: [열, 행]`, `.` = base 유지, `~` = 지움)로 적는다 — 깜빡임 검사(anim.flicker)는 patch 밖 base 영역을 비교한다.
  - 쓰러짐처럼 발이 떨어지는 프레임은 `"grounded": false`. 피격 첫 프레임은 `"fx": "flash"`.
  - death는 그림을 통째로 30° 넘게 돌리지 않는다(QA anim.pose-distinct) — 무릎 꿇기·주저앉기 단계를 그린다. attack·death 연속 키는 실루엣이 충분히 달라야 한다(IoU ≤ 0.9).
  - 기본 프레임 수: rest + idle 4 · attack 4 · hit 2 · death 3. 반복은 `loop`(기본 idle).
- **atoms**: 파츠마다 `shape: { "type": "grid", ... }`, 뼈가 배치한다.
  - **아톰 분할**: 시안 그리드의 칸을 머리(귀 등 특징은 따로)·몸통(chest·spine)·위팔/아래팔/손·허벅지/정강이·무기로 나눈다. 파츠마다 `anchor: "joint"`, `orient: "world"`, `origin` = rest 관절 위치(시안 좌표 − 파츠 bbox 왼쪽 위). 그러면 rest가 시안과 픽셀 단위로 같다(`forge compare`의 `refs.<id>`: iou·diff·headDiff로 확인).
  - 관절이 그린 해부 위치(어깨·팔꿈치·손·엉덩이)와 1px 안에 오도록 리그 비율을 확인한다(리그 변경은 사용자 승인).
  - 팔다리는 각도 변형을 따로 그린다: `variants: { "45": {...}, "-45": {...}, "90": {...} }`(파츠 각도에 가장 가까운 변형 + 남은 각도만 RotSprite). 변형 없이 크게 돌면 경고가 qa에 남는다.
  - 머리는 `"upright": true`(±15° 이내는 1px 이동만).

## 2. 그리드 범례
- `"<문자>": "<재질>:<단계>"`(예 `"3": "bone:2"`), `.` = 투명. 재질·단계는 바이블 램프 안이어야 한다(`forge validate`가 검사).
- `"@eye"` = 검은 눈(외곽선색, 정리 보호), `"@eye:<재질>:<단계>"` = 그 색 눈, `"@outline"` = 그 칸에 외곽선색 강제(입 틈·관절 구분선).
- 색 변형은 범례 재질만 바꾸면 된다(팔레트 교체가 자동 적용).

## 3. 설계 체크리스트 (그리기 전·후 매번)
1. **실루엣 먼저**: 단색으로 칠해도 종류가 읽히는가(그리드를 `#`만으로 바꿔 상상).
2. **특징 1개**: 귀·해골·뿔 등 하나가 읽히게(`signature` + 파츠 `signature: true`). 면적은 15~40% 밖일 때만 경고(form.signature, 선택). **수치 기준을 맞추려고 디자인을 과장하지 말 것. 시안·레퍼런스와의 비교가 우선**이고, 특징 판정은 pixel-reviewer의 "역할 원형 판독" 항목이다.
3. **머리 비율**: 소형 몬스터 머리 = 키의 40~50%.
4. **광원**: 왼쪽 위가 밝고 오른쪽 아래가 어둡다(밝은 단계는 왼쪽·위 가장자리, 어두운 단계는 오른쪽·아래).
5. **2px 이하 고립 조각 금지**: 같은 색 1~2칸 섬을 남기지 않는다(form.detail-min).
6. **눈은 가장 밝은 색 대비**: 눈(또는 눈 주변)은 얼굴에서 명도 차가 가장 큰 곳. 검은 눈이면 둘레를 밝게.

## 4. 루프 (최대 4회)
1. 그리드 작성·수정 → `pnpm -s forge validate <spec>`.
2. `pnpm -s forge render <spec> --sheet 8` → `out/<id>/studio.png`(rest + 전 프레임, 게임 배경, 8배) 1장.
3. `pixel-reviewer`에게 그 1장 + 기준 시안을 주고 채점(점수 /24, 시안 대비 판정). 메인에서는 이미지를 열지 않는다.
4. 지적 반영. 4회 안에 목표(20/24 + 시안 대비 같은 수준 이상)에 못 미치면 멈추고 점수·상위 문제 3개를 보고.
5. 통과하면 /forge의 4단계(build-all → review-score → apply)로.

## 금지
- 렌더러·QA 코드 수정, rules·바이블 수치 변경(제안만), 상용 스프라이트 복사(시안은 이 프로젝트에서 설계한 것만).
- 그리드에 외곽선 그리기(외곽선은 엔진 몫, 강제할 칸만 `@outline`).
